# Dataview

**Dataview**는 [[contents/Obsidian_karpathy_llm_wiki]]에서 각 마크다운 문서 상단에 작성된 YAML Frontmatter(메타데이터)를 데이터베이스처럼 다뤄 동적으로 쿼리 및 테이블을 생성해 주는 인기 커뮤니티 플러그인입니다.

LLM Wiki에서 LLM이 페이지를 자동 생성할 때 날짜, 출처 수, 연관 태그 등의 YAML 속성을 기재하게 설계해 두면, Dataview 플러그인을 활용하여 전체 위키의 상황판이나 대시보드, 특정 조건에 부합하는 문서 목록을 실시간으로 화면에 렌더링할 수 있어 지식의 구조적 가시성을 극대화합니다.
