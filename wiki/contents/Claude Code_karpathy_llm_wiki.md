# Claude Code

**Claude Code**는 Anthropic사에서 제공하는 개발자용 터미널 기반(CLI)의 자율형 AI 에이전트 도구입니다.

사용자의 컴퓨터 환경에서 쉘 명령어를 실행하고 파일을 읽고 쓸 수 있는 권한을 가진 대표적인 에이전트 예시로 글 서두에 나열됩니다. LLM Wiki에서 사용자가 수동으로 처리하기에는 지나치게 번거로운 문서 간 상호 교차 참조 업데이트, 인덱스 알파벳 정렬, 로그 갱신 등의 장부 정리 업무([[contents/Bookkeeping Automation_karpathy_llm_wiki]])를 터미널 상에서 자율적으로 조율하고 완료하는 실행자 역할을 수행합니다.
