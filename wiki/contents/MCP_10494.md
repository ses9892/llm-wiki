# MCP (Document 10494)

Model Context Protocol(MCP)은 AI 에이전트가 외부 데이터 소스나 기능을 표준화된 인터페이스로 탐색하고 사용할 수 있게 해주는 통신 규약으로, [[contents/designlang_10494]]은 자체 MCP 서버 구동을 완벽히 지원한다.

## 기능 및 활용

- **`designlang mcp` 명령어**: 이 명령어를 실행하면, 추출된 디자인 토큰, 감지된 레이아웃 영역(region), 컴포넌트 정보, 웹 접근성 명암비 분석 데이터 등이 MCP 리소스(Resources) 및 도구(Tools)의 형태로 노출된다.
- **에이전트 연동**: [[contents/Cursor_10494]] 및 [[contents/Claude Code_10494]] 같은 MCP 지원 AI 클라이언트들이 이 서버에 접속하여, 개발자 대신 실시간으로 타겟 웹사이트의 레이아웃 특징이나 컴포넌트 변형 명세를 쿼리하여 활용할 수 있다.
