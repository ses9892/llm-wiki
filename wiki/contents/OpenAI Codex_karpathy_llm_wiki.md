# OpenAI Codex

**OpenAI Codex**는 OpenAI에서 개발한 자연어 명령을 코드로 변환해 주는 거대 언어 모델 기반의 초기 프로그래밍 조력 모델입니다.

카파시의 글 초반에서 LLM Wiki 아이디어를 직접 이식하여 함께 협업해 나갈 수 있는 LLM 에이전트 예시 중 하나로 언급됩니다. [[contents/Claude Code_karpathy_llm_wiki]]나 [[contents/OpenCode_karpathy_llm_wiki]]와 같은 현대적 개발자 지향 CLI/에이전트 툴들과 연계하여 사용자가 위키 관리 자동화 시스템을 구상하고 실현할 때 조력자로 쓸 수 있는 기저 지능으로 분류됩니다.
